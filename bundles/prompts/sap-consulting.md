Use the `SAP Consulting` bundle.

Pick by situation:
- `bs-sap-support` while the location of an error is still unknown (dump, cancelled job, missing posting, error message)
- `bs-sap-abap-review` once ABAP source is on the table and has to be judged, explained or extended
- `bs-sap-kickoff` before the first line of a new development (enhancement technique, package, ABAP Cloud or classic)
- `bs-sap-spec` for functional and technical specifications and change requests
- `bs-sap-estimate` whenever a number for days or money is asked
- `bs-sap-ui5` for SAPUI5, Fiori Elements, OData and Launchpad work

Meeting follow-up and HTML documents come from `office-docs`.
