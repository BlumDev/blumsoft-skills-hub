# Kalibrierung: Schätzung gegen Ist

Nach jedem abgeschlossenen Vorgang eine Zeile ergänzen. Der Zweck ist der
eigene systematische Fehler, nicht eine allgemeine Kennzahl. Erst ab etwa
fünf Einträgen entsteht ein Muster, das sich zum Schätzen verwenden lässt.

Keine Kundennamen, keine Systembezeichnungen. Die Art des Vorgangs genügt.

| Datum | Vorgang (Art, Umfang) | Geschätzt (o / w / p) | Ist | Abweichung | Woran es lag |
|---|---|---|---|---|---|
| | | | | | |

## Was in die letzte Spalte gehört

Nicht "hat länger gedauert", sondern die Ursache in der Kategorie, in der sie
beim nächsten Mal wiedererkennbar ist. Zum Beispiel: Testdaten fehlten,
Entscheider nicht erreichbar, Altcode schlechter als erwartet, Schnittstelle
verhielt sich anders als dokumentiert, Abnahme zog zwei zusätzliche Runden.

## Auswertung

Sobald mehrere Einträge vorliegen, hier festhalten, was sich zeigt:

- Welche Positionsart wird regelmäßig zu niedrig geschätzt
- Um welchen Faktor liegt der Ist-Wert typischerweise über dem wahrscheinlichen
- Bei welcher Vorgangsart ist die Streuung so groß, dass nur eine Bandbreite
  mit Klärungsauftrag sinnvoll ist
